# CapSwap

**문구와 타이밍은 그대로, 자막 디자인만 교체.**

CapSwap은 Windows용 Adobe Premiere Pro 무료 패널입니다. 캡션을 원하는 모션 그래픽 템플릿(MOGRT)으로 바꿔 주고, 이미 배치한 그래픽 자막의 템플릿도 교체합니다. 문구를 다시 입력하거나 타이밍을 다시 맞출 필요가 없습니다. [English](README.md)

## 다운로드

**[최신 릴리스 받기](../../releases/latest)**에서 `CapSwap-<버전>-windows.zip`을 받으세요.

릴리스마다 서명된 `.zxp`의 SHA-256 값을 함께 적어 둡니다. 설치 배치도 설치 전에 이 값을 확인합니다.

CapSwap은 스스로 업데이트를 확인하지 않습니다(인터넷에 접속하지 않음). 새 버전 소식을 받으려면 이 페이지 위쪽의 **Watch → Custom → Releases**를 누르거나 [Ko-fi](https://ko-fi.com/vex26)를 팔로우하세요.

설치 배치를 실행할 때 보안 경고(예: "Windows의 PC 보호")가 뜨면 **추가 정보 → 실행** 또는 **실행**을 누르세요. 인터넷에서 받은 스크립트에 Windows가 표시하는 경고이며, 설치 배치는 설치 전에 패키지를 직접 검증합니다.

## 기능

- **캡션 → 그래픽 자막 일괄 생성**: 시퀀스의 캡션 트랙에서 문구와 시작·끝 시각을 그대로 읽어 지정한 MOGRT로 배치합니다. SRT 내보내기나 시간 보정이 필요 없으며, SRT 파일로도 만들 수 있습니다.
- **선택한 자막의 템플릿 교체**: 타임라인에서 고른 그래픽 자막을 다른 MOGRT로 바꿉니다. 현재 문구, 타이밍, 비디오 트랙, 활성 상태는 유지됩니다.
- **마지막 템플릿으로 즉시 교체**: 마지막으로 교체에 성공한 템플릿을 버튼 한 번으로 다시 적용합니다.
- **템플릿 브라우저**: 로컬 MOGRT를 썸네일로 탐색합니다. 검색, 폴더 등록, 즐겨찾기, 최근 선택을 지원합니다.
- **영어·한국어**: Premiere 언어를 자동으로 따르며, 패널에서 직접 바꿀 수도 있습니다.

## 안전장치

- 새 자막을 검증한 뒤에만 원본 자막을 지웁니다. 실패하거나 취소하면 원본은 그대로 남습니다.
- 일괄 생성 전, 그리고 6개 이상 교체하기 전에는 시퀀스를 백업합니다. 프로젝트의 `CapSwap 백업` 폴더에 최근 3개를 보관합니다.
- 프로젝트 파일과 MOGRT 파일은 직접 수정하지 않습니다.
- 인터넷에 접속하지 않습니다. 패널의 Ko-fi 링크는 누를 때만 브라우저를 엽니다.

## 지원 환경

- Windows 10 또는 11, 64비트(Windows 11에서 시험)
- Adobe Premiere Pro 26.5 이상(26.5.2에서 검증). 아직 검증하지 않은 새 버전에서는 작업 전에 한 번 확인을 받습니다.
- macOS는 지원하지 않습니다.

## 설치

1. `CapSwap-<버전>-windows.zip`의 압축을 풀고 Premiere Pro를 종료합니다.
2. **Install-CapSwap.cmd**를 더블클릭합니다. 관리자 권한은 필요 없습니다.
3. Premiere Pro에서 **창 → 확장 → CapSwap**을 선택합니다.

제거하려면 명령 프롬프트에서 `Install-CapSwap.cmd uninstall`을 실행합니다. 설정은 남겨 둡니다.

설치 배치가 하는 일:
- Premiere가 종료되었는지 확인합니다.
- 패키지의 체크섬과 서명을 확인합니다.
- 기존 설치를 백업한 뒤 교체합니다.
- 레지스트리는 건드리지 않습니다.

## 빠른 시작

1. 캡션이 있는 시퀀스를 엽니다.
2. **찾아보기**로 기본 MOGRT를 지정하고, 빈 비디오 트랙을 고릅니다.
3. **기본 템플릿으로 일괄 생성**을 누른 뒤, 원본 캡션 트랙을 숨깁니다.
4. 나중에 디자인을 바꾸려면 그래픽 자막을 선택하고 **다른 MOGRT 선택 후 교체**를 누릅니다.

## 알려진 제한

- 기존 자막의 효과, 위치 키프레임, 강조 색상, 여러 스타일 구간은 옮기지 않습니다. 글자 수가 바뀌면 레이아웃을 확인하세요.
- 캡션의 글꼴·색상·위치는 가져오지 않으며, 디자인은 템플릿을 따릅니다.
- After Effects MOGRT와 23.976fps·29.97fps 드롭프레임 시퀀스는 아직 충분히 검증하지 않았습니다.
- 오디오가 있는 템플릿, 속도를 바꾼 자막, 연결 클립은 지원하지 않습니다.
- 작업 전체를 한 번에 되돌리는 기능은 없습니다. 백업 시퀀스나 Premiere의 실행 취소를 사용하세요.
